# neuro-co

`neuro-co` is a Python workspace for neural combinatorial optimization. It
contains PyTorch and JAX policies, routing and scheduling environments, energy
accounting, explanation methods, and tools for large routing experiments.

- [Getting started](getting-started.md): installation and a small training run.
- [Training](training.md): PyTorch, Mamba, JAX, and checkpoint formats.
- [Energy accounting](aet.md): measurement scope and AET reports.
- [Scaling](scale.md): hierarchical routing and resumable training.
- [Development](development.md): workspace checks and reproducibility.
